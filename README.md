# Quantum Coherence & Decoherence Presentation

A beautifully animated Flutter presentation application explaining the concepts of Quantum Coherence and Decoherence across 5 interactive slides.

## Features
- **5 Educational Slides**: Covers the basics of quantum coherence, superposition, decoherence, and their implications in computing.
- **Cross-Platform**: Runs seamlessly on Web, Desktop, iOS, and Android.
- **Responsive Design**: Adapts beautifully to both wide desktop screens and narrow mobile displays.
- **Animated Transitions**: Smooth fade transitions between slides to keep viewers engaged.

## Setup & Run

Ensure you have [Flutter installed](https://docs.flutter.dev/get-started/install).

1. Clone the repository
2. Install dependencies:
   ```bash
   flutter pub get
   ```
3. Run the app:
   ```bash
   flutter run
   ```

## Tech Stack
- Framework: Flutter
- Language: Dart
- State Management: Stateful Widgets
